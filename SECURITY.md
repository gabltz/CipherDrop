# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** using GitHub's "Report a vulnerability" (private security advisories) on this repository. Do not open public issues for security problems.

Include affected versions, reproduction steps and impact. Use synthetic data only. We aim to acknowledge reports within 5 business days.

## Scope

In scope: the server, protocol, SDKs, CLI, web interface, container image and deployment examples.
Out of scope: issues requiring a compromised endpoint, a malicious server operator serving modified web code (documented limitation), or volumetric DDoS.

## Audit status

CipherDrop has **not** been independently audited. No guarantee of security is made. See [THREAT_MODEL.md](THREAT_MODEL.md) and [docs/security.md](docs/security.md).

## Supported versions

Only the latest release receives security fixes.
